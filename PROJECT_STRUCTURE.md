# Структура проекта "Город теней"

## Обзор

Проект реализует игру-головоломку от первого лица на Three.js + TypeScript, где игрок должен найти скрытые объекты по их теням от движущегося источника света.

## Структура директорий

```
city-of-shadows/
├── index.html              # Главная HTML страница
├── package.json            # Зависимости и скрипты
├── tsconfig.json          # Конфигурация TypeScript
├── vite.config.ts         # Конфигурация Vite
├── README.md              # Описание проекта
│
└── src/
    ├── main.ts            # Главный файл приложения
    ├── styles.css         # Стили UI
    │
    ├── core/              # Основные модули
    │   ├── input.ts       # Обработка ввода (клавиатура, мышь)
    │   ├── curve.ts       # Траектория движения света (CatmullRom)
    │   ├── placement.ts   # Размещение объектов с фильтрами коллизий
    │   ├── hit.ts         # Система проверки попадания по объектам
    │   └── timer.ts       # Таймер игры
    │
    ├── render/            # Модули рендеринга
    │   ├── scene.ts       # Построение сцены (приёмники теней)
    │   ├── shadows.ts     # Настройка системы теней
    │   └── post.ts        # Постобработка (опционально)
    │
    └── game/              # Игровая логика
        ├── world.ts       # Мир игры, управление светом
        ├── objectives.ts  # Управление целями игры
        └── ui.ts          # Управление пользовательским интерфейсом
```

## Основные компоненты

### Core модули

- **input.ts**: Обработка клавиатуры, мыши, PointerLock
- **curve.ts**: Управление траекторией света по CatmullRom кривой
- **placement.ts**: Размещение объектов с проверкой коллизий и расстояний
- **hit.ts**: Система рейкастинга для пометки объектов
- **timer.ts**: Таймер игры с форматированием времени

### Render модули

- **scene.ts**: Построение сцены (пол, стены, арки) с ShadowMaterial
- **shadows.ts**: Настройка теней (PCFSoftShadowMap, SpotLight)
- **post.ts**: Постобработка (заглушка для будущего FXAA)

### Game модули

- **world.ts**: Управление миром, движением света, размещением объектов
- **objectives.ts**: Отслеживание найденных объектов, проверка победы
- **ui.ts**: Управление UI (меню, HUD, экран победы)

## Особенности реализации

1. **Система теней**: PCFSoftShadowMap с настраиваемым качеством (Low/Med/High)
2. **Скрытые объекты**: Невидимые в цветном проходе, но участвуют в тенях и рейкасте
3. **Траектория света**: CatmullRom кривая с предвычисленными длинами дуг
4. **Стоп света**: Пауза движения света на 3 секунды с кулдауном 10 секунд
5. **Система попадания**: Рейкастинг от камеры с проверкой расстояния до центра объекта

## Запуск

```bash
# Установка зависимостей
npm install

# Разработка
npm run dev

# Сборка
npm run build
npm run preview
```

## Управление

- **Клик** - захват мыши (PointerLock)
- **WASD** - движение
- **Space** - прыжок (заглушка)
- **Ctrl** - приседание (заглушка)
- **ЛКМ** - пометка объекта
- **Shift** - остановить свет (кулдаун 10с)
- **ESC** - меню/выход из PointerLock

## Конфигурация

Основные параметры в `src/main.ts`:

```typescript
const CFG: WorldConfig = {
    sceneSize: 80,
    difficulty: 'normal',      // easy/normal/hard
    shadowQuality: 'med',      // low/med/high
    lightSpeed: 4.0,
    lightPauseDuration: 3.0,
    lightCooldown: 10.0,
    hitMaxDist: 25,
    hitTolerance: 0.6
};
```
