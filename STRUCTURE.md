# Структура проекта "4D-Пещера: Найди все огни"

## Обзор

Проект реализует шутер-бродилку от первого лица в процедурной 4D-пещере на Python 3.11.

## Основные компоненты

### Core модули

- **math.py**: Класс Vec3, матрицы преобразований (look_at, perspective, rotate)
- **noise4d.py**: 4D OpenSimplex шум с domain warping на numba для производительности
- **field.py**: 4D скалярное поле с периодизацией по координате w
- **mc.py**: Marching Cubes алгоритм для генерации мешей из воксельных данных
- **chunks.py**: Управление чанками 32³ вокселей с кэшированием по w_bin
- **physics.py**: Физика игрока (капсула, движение, гравитация)
- **gen.py**: Генерация стартовой точки и размещение коллектиблов (Poisson disk)

### Render модули

- **window.py**: GLFW окно, обработка клавиатуры и мыши
- **renderer.py**: moderngl контекст, загрузка мешей в GPU, отрисовка
- **shaders/**: GLSL шейдеры для пещеры (Ламбертово освещение, туман) и свечений

### Game модули

- **state.py**: Конечный автомат состояний (menu, playing, pause, victory)
- **world.py**: Управление миром, генерация уровня, обновление систем
- **player.py**: Игрок, камера, фонарик, управление координатой w
- **pickups.py**: Коллектиблы с пульсирующим свечением
- **exit_portal.py**: Выходной портал, активируется после сбора всех коллектиблов
- **ui.py**: HUD (заглушка, в полной версии будет текст)

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Управление

- **WASD** - движение
- **Space** - прыжок
- **Ctrl** - приседание
- **Мышь** - взгляд
- **Q/E** или **Колёсико мыши** - изменение 4-й координаты w
- **F** - переключение режимов фонаря (узкий/широкий луч)
- **R** - новое зерно генерации
- **Esc** - меню/пауза

## Особенности реализации

1. **4D процедурная генерация**: Используется 4D шум с domain warping и периодизацией по w
2. **Marching Cubes**: Генерация мешей из воксельных данных
3. **Чанкинг**: Разбиение мира на чанки 32³ с кэшированием по w_bin
4. **Оптимизация**: numba для критических вычислений, ограничение треугольников
5. **Фонарик**: Точечный источник света с конусом, два режима (узкий/широкий)

## Конфигурация

Основные параметры в `config.yaml`:
- Параметры шума (octaves, lacunarity, gain, sigma)
- Размеры сетки (chunk, cell_size, region_size)
- Параметры игрока (speed, jump, radius, height)
- Параметры рендеринга (fov, fog_distance, max_tris)
